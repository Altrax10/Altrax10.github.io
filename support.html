GabotClips Studio Support

Support

If you need help with GabotClips Studio, report a problem, or have a question about the TikTok integration, use the developer's GitHub profile.

Contact the developer

Open GitHub profile

When reporting an issue, include the GabotClips Studio version, Windows version, the steps that caused the problem, and any relevant error message. Do not post passwords, TikTok authorization codes, access tokens, or other secrets.

TikTok integration

For issues related specifically to your TikTok account or TikTok service, you may also need to use TikTok's official support channels. GabotClips Studio cannot access or change your TikTok password.
